# Pinterest as a design-research source

For substantial new or unlocked visual work, include Pinterest in the inspiration
research alongside real websites and original designers. Preserve an approved
brand or layout; a small fix does not reopen art direction.

Search by the actual product, material and composition question, such as
"ceramics editorial web design", rather than only "premium landing page". Inspect
accessible pins or boards for typography, crop, color relationships, section
rhythm and component anatomy. Open the linked original designer or live website
when available: a pin is discovery, not proof of responsiveness or working motion.

Record a small reference set in `design-brief.md`: source URL, what was actually
inspected, the transferable principle, how it changes for this product, and what
will not be copied. Combine principles into one original direction; do not
reproduce a whole layout, distinctive branding, artwork or copy. A pin does not
grant image rights. Source implementation assets separately with verified usage
terms, or use the user's assets.

Pinterest is a research source, not an installed skill or runtime dependency.
Use public pages or an already available browser session. Do not require account
creation, ask for credentials, bypass a login wall, save pins or create boards.
If access is blocked, record it and continue with original designer sites,
accessible references or other design directories. Never label a search result
or inaccessible pin as a rendered-page inspection. Show the selected inspiration
sources with the written design preview before implementation.

# Existing interface redesign

The original redesign-existing-projects workflow was merged upstream into the
current [Taste Skill](../companions/taste/GUIDE.md). Use that maintained guide
with Colabio's existing-interface workflow. First inspect routes, working
behavior, real content, responsive constraints, and the incumbent visual system.
Preserve the requested product scope while replacing the visual direction only
when a redesign is requested. Verify structure and interactions, not just colors.
Use [Emil design engineering](../modules/emil-design-eng/GUIDE.md) for interaction
polish and [mobile-native](../modules/mobile-native/GUIDE.md) for mobile web fit.
This is an original adapter, not a claimed copy of the retired upstream skill.

## Awesome DESIGN.md

[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
is a collection of design-system analyses and links, not a runnable skill.
It is MIT-licensed; externally hosted analyses and referenced assets may have
separate terms. Read linked content before describing it as a studied reference.

Useful starting points from the reviewed index:

| Design problem | Analysis | What to investigate |
| --- | --- | --- |
| Clear technical product hierarchy | [Vercel](https://getdesign.md/vercel/design-md) | Typographic scale, hierarchy, restrained surfaces |
| Story-led creative product | [Runway](https://getdesign.md/runwayml/design-md) | Media proportion, reading rhythm, contrast between scenes |
| Readable editorial AI product | [Claude](https://getdesign.md/claude/design-md) | Reading measure, warmth, text/action relationships |
| Data and developer explanation | [Together AI](https://getdesign.md/together.ai/design-md) | Diagram language, technical information hierarchy |

Choose two or three that fit a substantial open brief. These are starting
queries, not a requirement to emulate these brands. Find a more relevant entry
when the project calls for it. Extract mechanisms, then derive actual fonts,
colors, layout, assets, and component behavior from the user's project.

Do not install this repository as an agent skill or copy a brand's DESIGN.md
into the project as its new identity without a matching user brief. Do not infer
exact font/color values from these labels; open the analysis and verify them.
If access fails, disclose it and use the bundled
[research notes](design-research.md). Never claim unavailable content was read.
